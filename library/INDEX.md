# Library index — what is here and when to read it

Everything in `library/` is vendored open-source material (licenses inside each folder). Read this index at the start of every deck session, then open only the files the current phase needs. Sizes are small; nothing here needs a build step.

| Folder | Source (license) | What it holds | Read when |
|---|---|---|---|
| `vendor/` | GSAP 3.12 (free incl. all plugins since 2025), Motion, rough-notation, rough.js, vivus, Splitting | Drop-in JS/CSS for motion: springs, SplitText-style word builds, hand-drawn annotations, SVG draw-in | Phase 5 when a recipe in `reference/motion-system.md` calls for a library. Copy the file into `<deck>/lib/` and reference it relatively (decks are opened from `file://`). |
| `huashu-design/` | alchaincyf/huashu-design (MIT, 19.5k★, Chinese) | The deepest motion/design corpus in the set: `animation-best-practices.md` (Slow-Fast-Boom-Stop, expoOut, focus = blur+dim, pause before the key result), `animation-pitfalls.md` (24 real bugs), `apple-gallery-showcase.md` (Apple-style gallery wall: tokens, tilted 3D canvas, ripple, focus overlay, noise), `hero-animation-case-study.md`, `cinematic-patterns.md` (scene-based, not step-based), `gsap-recipes.md`, `camera-language.md`, `design-styles.md` (60 styles + colour derivation protocol), `typography.md` (modular scale, measure, 10 open pairings), `critique-guide.md` (scoring rubric), `slide-decks.md`, `verification.md`, `storyboard-basics.md`, `content-guidelines.md`, `brand-asset-protocol.md` | Phase 3 (design direction: `design-styles.md`), Phase 5 (motion: best-practices, pitfalls, apple-gallery), Phase 7 (critique-guide as a self-review rubric). |
| `next-slide/` | codesstar/next-slide (MIT) | `STYLE_PRESETS.md` — 36 fully specified style presets (palette, fonts, decorative vocabulary, per-style animation), `styles/*.html` — 56 single-file live demos (keynote-noir, swiss-grid, risograph-overprint, blueprint-tech, newsprint-broadsheet, wabi-sabi-zen, art-deco-gatsby, terminal-green, …), `animation-patterns.md` (mood → animation map), `SCENARIO_TEMPLATES.md` (deck arcs by occasion) | Phase 3 — open 2–3 demos that match the vibe and steal the vocabulary, never the whole file. |
| `html-ppt-skill/` | lewislulu/html-ppt-skill (MIT) | `animations.md` (47 named animations, catalog), `animations/animations.css` (27 ready classes: blur-in, kenburns, path-draw, ripple-reveal, shimmer-sweep, spotlight, page-turn-3d…), `animations/fx/*.js` (20 tiny canvas effects: constellation, starfield, gradient-blob, data-stream, particle-burst, word-cascade…), `themes.md` (36 themes), `layouts.md` (31 layouts), `presenter-mode.md` | Phase 5 when you need a ready CSS effect or a one-slide canvas ambient; presenter mode if the user asks for speaker notes. |
| `visual-cognition-slides/` | edu-ai-builders (MIT, Chinese) | `PEDAGOGY.md` — narrative structures, knowledge-type → visual form, cognitive-science cheat sheet, audience strategies; `ANIMATIONS.md` — 13 families of *explanatory* animations (analogy, mechanism, comparison, data, timeline, framework, physics, discipline, impact, relations, narrative curve, metacognition); `STYLES.md`, `FORMATS.md`, `INTERACTION.md` | Phase 2 for teaching/seminar decks (the user's decks are academic): pick the explanation pattern per section before choosing visuals. |
| `skills-slides/` | nghiahsgs/skills-slides (MIT) | `tokens/*.csv` (50 aesthetics × 20 palettes × 10 pairings × layouts × 35 effects), `references/anti-slop-checklist.md`, `css-effects-cookbook.md`, `animation-patterns.md` | Phase 3 (query tokens by vibe), Phase 7 (anti-slop gate). |
| `claude-slides/` | marcogalluccio/claude-slides (MIT, Italian text) | `components.md` (cards, mockups, terminals, flow pipelines), `animations.md` (step reveals, path drawing, packets, magic-move), `icons.md` | Phase 5 for component patterns. |
| `claude-design/` | jiji262/claude-design-skill (MIT) | `style-gallery/*.html` — 10 built style demos (Swiss editorial, Bauhaus, Kenya Hara, Dieter Rams, magazine, zine/riso, field.io, brutalist, Sagmeister, Y2K), `assets/` (deck-stage, device frames) | Phase 3 for direction, Phase 5 for device frames. |
| `anthropic-frontend-design/`, `anthropic-theme-factory/` | anthropics/skills (Apache-2.0) | Anti-generic design guidance; 10 safe corporate themes | Phase 3 sanity check; corporate decks. |

Not vendored (read online, licence or size): op7418/guizang-ppt-skill (AGPL — WebGL shader backgrounds, Swiss layout lock, 634-line checklist: github.com/op7418/guizang-ppt-skill), kaisersong/slide-creator (no licence — `references/design-quality.md`, `review-checklist.md`, `impeccable-anti-patterns.md`; the rules are summarised in `reference/perception.md` and `reference/taste.md`), software-ai-life/Awesome-PPT-Design-Skills (no licence — 6 style packs: Japanese, clay 3D, luxury branding, hand-drawn editorial, futuristic tech, illustration), zarazhangrui/beautiful-html-templates (66 MB; recipes already in `~/.claude/skills/frontend-slides/bold-template-pack/`).
